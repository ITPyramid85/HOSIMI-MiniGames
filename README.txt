HOSIMI Drum Rhythm Game - Unity Project
=======================================

[Unity version]
Unity 6000.0.32f1 (Unity 6, revision b2e806cf271c)
- Please open the project with exactly this version. Opening it with a different
  version may upgrade and modify scenes and prefabs.
- You can install it from Unity Hub > Installs > Install Editor > Archive.

[How to open]
1. Unzip the archive (a folder path without non-ASCII characters is recommended).
2. In Unity Hub, go to Projects > Add and select the "HOSIMI_Unity" folder.
3. The first launch rebuilds the Library folder, which takes a few minutes.
4. Open Assets/Scenes/MainMenu.unity and press Play.

[Contents]
- Assets/           Game source code, scenes and resources
- ProjectSettings/  Project settings
- Packages/         Package manifest (Input System, URP, Test Framework, etc.).
                    Required - without it the project will not compile.
- docs/             Game proposal v6 and the app UI draft v1 review reply v5

The Library, Logs and UserSettings folders are not included; Unity regenerates them automatically.
